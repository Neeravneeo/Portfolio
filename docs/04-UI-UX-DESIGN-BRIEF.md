# NEERAV.OS Portfolio — UI/UX Design Brief

Version: 1.1

---

## 1. Public Visual Direction

Premium cinematic cosmic interface.

### Keywords:
- Cosmic
- Spatial
- Minimal
- Futuristic
- Editorial
- Precise
- Premium
- Experimental

### Avoid:
- Generic cyberpunk
- Excessive neon
- Excessive glass cards
- Random 3D decorations
- Over-animated transitions
- Dashboard-like homepage clutter

---

## 2. Visual System

### Background
Near-black / deep navy (`#05070d` / `#080b14`).

### Primary
Electric violet (`#8b5cf6`).

### Secondary
Cyan / blue (`#06b6d4` / `#3b82f6`).

### Supporting
Controlled teal/green (`#10b981`).

### Typography
Modern grotesk/sans-serif with occasional mono labels.

---

## 3. Public Navigation

Minimal top navigation:
```
NEERAV.OS    Work  Journey  Lab  About  Contact
                         Designer | Engineer
```

---

## 4. Admin Visual Direction

Admin Studio should use the same NEERAV.OS design language but become much more practical.

*Do not make the admin dashboard a giant cinematic 3D experience.*

### Use:
- Dense but readable data tables.
- Sidebar navigation.
- Clear forms.
- Status badges.
- Charts.
- Search.
- Filters.
- Confirmation dialogs.
- Upload areas.
- Draft/published states.

*The public site is expressive. The admin is functional.*

---

## 7. Analytics UI

### Show:
- Visitors
- Sessions
- Views
- Project engagement
- CTA clicks
- Contact submissions
- Top pages
- Top projects
- Date range

Use charts that answer questions. Do not add meaningless analytics.

---

## 8. Public Interaction Rules

- **ALZO:** Horizontal role switching + vertical role journey.
- **Peer Club:** Mode switching.
- **GitDrive:** Workflow progression.
- **AI Email Agent:** Pipeline progression.
- **Timeline:** Orbital milestones.
- **Lab:** Interactive experiment cards.

---

## 9. Responsive Rules

### Desktop:
- Large 3D.
- Spatial layouts.
- Side panels.
- Horizontal exploration.

### Mobile:
- Simplified 3D.
- Tap/swipe.
- One focused panel.
- Stacked diagrams.
- No hover dependency.

---

## 10. Accessibility

- Keyboard support.
- Focus states.
- Reduced motion.
- High contrast.
- Semantic headings.
- Alt text.
- Touch-friendly controls.
